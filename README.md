# TeamFuse 🚀

TeamFuse is a comic-inspired teammate matching platform that helps users find suitable teammates based on their skills, roles, and experience.

## ✨ Features

- Create your profile
- Add your skills
- Select the skills you are looking for
- Discover potential teammates
- Search teammates by name or skill
- Filter teammates by role
- View compatibility match percentage
- Add teammates to your team
- Analyze team skill coverage
- Identify missing skills
- Get a TeamFuse team verdict

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- LocalStorage

## 🎯 How It Works

1. Create your profile
2. Select your skills and required teammate skills
3. Find suitable teammates
4. Search and filter teammates
5. Add teammates to your team
6. Build your team
7. View the team analysis

## 🎨 Design

TeamFuse features a unique comic-book-inspired UI with bold typography, thick borders, offset shadows, colorful cards, and playful interactions.

TeamFuse is currently a frontend prototype using LocalStorage for profile and team data.
